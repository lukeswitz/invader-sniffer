CLI flash

bash <(curl -fsSL https://raw.githubusercontent.com/lukeswitz/invader-sniffer/main/flash.sh)

How to flash

1 Use Chrome or Edge (WebSerial required)
2 Connect board via USB
3 Hold BOOT, tap RST, release BOOT
4 Click flash button above and select serial port
5 Wait for flash to complete, then tap RST to boot
